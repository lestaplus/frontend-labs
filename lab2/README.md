# Лабораторна робота №2 | [Github Pages](https://lestaplus.github.io/frontend-labs/lab2/)

## Інструкція з локального запуску

1. Склонуйте репозиторій 

```bash
git clone https://github.com/lestaplus/frontend-labs.git
```

2. Перейдіть в папку лабораторної роботи

```bash
cd lab2
```

3. Відкрийте файл `index.html` у будь-якому веб-браузері або запустіть через Live Server у VS Code.
