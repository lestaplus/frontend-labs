# Лабораторна робота №3 | [Github Pages](https://lestaplus.github.io/frontend-labs/lab3/)

## Інструкція з локального запуску

1. Склонуйте репозиторій 

```bash
git clone https://github.com/lestaplus/frontend-labs.git
```

2. Перейдіть в папку лабораторної роботи

```bash
cd lab3
```

3. Відкрийте файл `index.html` або `flex.html` у будь-якому веб-браузері або запустіть через Live Server у VS Code.
